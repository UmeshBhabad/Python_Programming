// MultiThreading amd Multiprocessing


Program : It is static set of instruction written in high level language

process : THe running instance of the program
    e.g person(born -> death)

Thread : it is a part of process
    e.g (bearthing, blood circulation, hearing etc)

Multi tasking : 
    a. Multithreading : I/O bound 
                            Single process with multiple threads
    b. Multiprocessing : CPU bound
                            multiple processes with single thread

GIL : Global Interpreter Lock
